# SLO templates

Copy these, then replace every `<...>` placeholder. A [filled-in example](../examples/checkout-api/) shows the finished result.

| Template | Use it when |
| --- | --- |
| [`slo-document.md`](slo-document.md) | Agreeing reliability targets for a service, in words people can review |
| [`slo.yaml`](slo.yaml) | Writing the same targets for the [SLO tool](../../tools/), which generates alerts |
| [`error-budget-policy.md`](error-budget-policy.md) | Agreeing with leadership what happens when targets are missed |
