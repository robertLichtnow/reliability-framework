# Incident response templates

Copy these, then replace every `<...>` placeholder.

| Template | Use it when |
| --- | --- |
| [`runbook.md`](runbook.md) | Before an incident: writing the steps for responding to one alert |
| [`status-update.md`](status-update.md) | During an incident: telling colleagues and customers what is happening |
| [`postmortem.md`](postmortem.md) | After an incident: reviewing what happened and what to change |
| [`cast-analysis.md`](cast-analysis.md) | After a serious or repeated incident: a deeper look at how the system's controls failed |
